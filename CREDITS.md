## Owner-approved transitive exceptions

The owner explicitly approved these three exceptions to the original README licence allowlist during this product-build task. The automated check permits only these package/licence pairs; it still rejects all GPL/AGPL licences and unknown additions.

- **caniuse-lite**, CC-BY-4.0: browser support data by the Can I Use contributors, https://github.com/browserslist/caniuse-lite and https://caniuse.com/. Licence: https://creativecommons.org/licenses/by/4.0/. Used unmodified by Next.js during compilation; attribution is retained here.
- **minimatch**, BlueOak-1.0.0: glob matching used by lint tooling, https://github.com/isaacs/minimatch. The package retains its copyright and Blue Oak Model License notice.
- **pako**, MIT AND Zlib: compression code used by pdf-lib. Copyright Vitaly Puzrin and Andrei Tuputcyn; zlib code derives from work by Jean-loup Gailly and Mark Adler. https://github.com/nodeca/pako. Licence notices are retained with the package and its bundled fontkit distribution.

Sharp and its LGPL libvips binaries are omitted because this static app does not use server-side image optimization.
